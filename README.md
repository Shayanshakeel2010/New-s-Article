# 📰 News Article Website

A simple and stylish **News Article Website** built using **HTML** and **CSS**. This project demonstrates how CSS can improve the appearance of a webpage by applying beautiful colors, backgrounds, typography, and links.

## ✨ Features

- 🎨 Colored headings for a modern look
- 🌈 Beautiful background colors
- 🔠 Capitalized first letter of each paragraph using CSS
- 🔗 Clickable navigation and external links
- 📱 Clean and responsive layout
- 💻 Beginner-friendly HTML & CSS project

## 🛠️ Technologies Used

- HTML5
- CSS3
